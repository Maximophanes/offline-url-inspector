# Version 3.1.2 complete copy and interface audit

This pass continues the existing uncommitted 3.1.2 implementation; it does not replace it with 3.1.1. The permanent standard is [EDITORIAL_STYLE_GUIDE.md](EDITORIAL_STYLE_GUIDE.md). The complete literal/text candidate inventory, source line numbers and source hashes are in `tests/copy-inventory.json`, generated by `tools/audit_copy.py`. That inventory deliberately includes code/data tokens: it is a traceability supplement, not a claim that every quoted token is user guidance. The family decisions below distinguish polished guidance from original technical evidence.

Every runtime-copy source was reviewed: `src/template.html`, `src/presentation.js`, `src/ui.js`, `src/references.js`, `src/core.js`, `src/hosted.js`, `src/sw.js` and `tools/build.py`. CSS-generated markers, Unicode name/script fallbacks, `data/unicode-data.json` and `data/LICENSE.txt` were also accounted for. Browser-owned file-picker/error-page wording is outside the application's control. CLI-only build validation errors are not presented as browser guidance.

Coverage references: **E** = `tests/editorial.mjs`; **C** = `tests/clarity.mjs`; **R** = `tests/refinement.mjs`; **P** = `tests/polish.mjs`; **D** = retained DOM/core/reference suites; **H** = `tests/hosted-bootstrap.mjs`; **W** = `tests/service-worker.mjs`; **HTTP** = `tests/http.mjs`; **B** = actual in-app observations in `tests/editorial-browser-preview.json`; **F** = pending real Firefox/accessibility checklist. Simulations do not establish actual Firefox, Container, screen-reader or file-policy behavior.
